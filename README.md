# ETS2 CarPlay

CarPlay-Oberfläche (iOS 26) für das Navi-Display in **Euro Truck Simulator 2**: Karte mit Navi-Route, Spotify, Auftrag, Fahrzeug, Blitzer, Telefon und mehr – direkt im Truck, mit Touch per Maus.

Dieses Repository enthält nur die fertigen **Releases**.

## Installieren
1. Euro Truck Simulator 2 beenden.
2. Neueste `ETS2-CarPlay-<Version>.zip` unter [Releases](../../releases) laden, entpacken, `ETS2 CarPlay.exe` starten.
   Die App findet ETS2 über Steam und installiert das Plugin selbst.
3. ETS2 starten und die SDK-Warnung bestätigen.

Updates spielt die App selbst ein (Einstellungen › Allgemein › Softwareupdate).
Deinstallieren: Einstellungen › Allgemein › ETS2 CarPlay deinstallieren oder `Deinstallieren.cmd` im Programmordner.

Enthält Teile des ETS2LA-Spielplugins (MIT) und den TruckSim-Kartenparser (GPL-3.0, Quelle siehe `resources/mapdata/parser/QUELLE.txt` im Paket). Schrift: Inter (SIL OFL 1.1).
