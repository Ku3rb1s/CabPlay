# ETS2 CarPlay

CarPlay-Oberfläche im Stil von iOS 27 für das Navi-Display in **Euro Truck Simulator 2**: Karte mit Navi-Route, Spotify, Auftrag, Fahrzeug, Blitzer, Telefon und mehr – direkt im Truck, mit Touch per Maus.

*An iOS 27 style CarPlay interface for the navigation display in **Euro Truck Simulator 2**: map with route guidance, Spotify, job, vehicle, speed cameras, phone and more – right in the truck, with mouse touch. English, metric/imperial units and 12/24-hour time are available in the settings.*

Dieses Repository enthält nur die fertigen **Releases**. · *This repository only contains the **releases**.*

## Installieren · Install
1. Euro Truck Simulator 2 beenden. · *Close Euro Truck Simulator 2.*
2. Unter [Releases](../../releases) `ETS2-CarPlay-Setup-<Version>.exe` laden und starten (Ordner frei wählbar) – oder die ZIP entpacken und `ETS2 CarPlay.exe` starten.
   *Download and run `ETS2-CarPlay-Setup-<version>.exe` from [Releases](../../releases) (choose any folder) – or unzip the ZIP and run `ETS2 CarPlay.exe`.*
   Die App findet ETS2 über Steam und installiert das Plugin selbst. · *The app finds ETS2 via Steam and installs the plugin by itself.*
3. ETS2 starten und die SDK-Warnung bestätigen. · *Start ETS2 and confirm the SDK warning.*

Updates spielt die App selbst ein (Einstellungen › Allgemein › Softwareupdate). · *The app installs updates by itself (Settings › General › Software update).*
Deinstallieren: Windows „Apps“, Einstellungen › Allgemein › ETS2 CarPlay deinstallieren oder `Deinstallieren.cmd`. · *Uninstall via Windows “Apps”, Settings › General › Uninstall ETS2 CarPlay or `Deinstallieren.cmd`.*

*Contains parts of the ETS2LA game plugin (MIT) and the TruckSim map parser (GPL-3.0, source see `resources/mapdata/parser/QUELLE.txt` in the package). Font: Inter (SIL OFL 1.1).*
